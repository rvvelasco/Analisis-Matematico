Integrales, desde cero

Qué es integrar (deshacer una derivada y calcular áreas), la tabla de integrales inmediatas, los métodos (sustitución, por partes, fracciones simples), la integral definida con Riemann y la regla de Barrow, el área entre curvas y las aplicaciones. Necesitás saber derivar: si no, empezá por la guía de Derivadas.

Si no tenés base de matemática, arrancá por la Matemática desde cero y después por la versión APB (paso a paso) de este tema. Esta guía es la versión completa, nivel parcial.

Cómo usar esta guía

Las palabras como esta abren su definición. Cada método tiene ejemplos que van de fácil a nivel parcial y una autoevaluación. Hay una sección "¿qué método uso?" para cuando no sabés por dónde arrancar. Para practicar: simulador, temas 28 a 32 y el parcial modelo de Integrales.

01

La idea: dos problemas que resultan ser el mismo

La integral nace de dos preguntas que parecen no tener nada que ver:

  • Problema 1 · "Deshacer" una derivada. Si sé que la velocidad es v(t) = 2t, ¿cuál es la posición? Busco una función cuya derivada sea 2t: t² (más una constante). Esa es una primitiva.
  • Problema 2 · Calcular un área. ¿Cuánto mide el área bajo la curva y = 2t entre 0 y 3? Es un triángulo de base 3 y altura 6: área 9. Y fijate: t² evaluado en 3 menos t² en 0 da 9 − 0 = 9.
En criollo

Derivar es pasar de la posición a la velocidad ("¿qué tan rápido cambia?"). Integrar es lo contrario: de la velocidad a la distancia recorrida ("si voy a tal velocidad, ¿cuánto acumulo?"). Integrar es sumar acumulados, y por eso aparece el área.

02

Primitiva e integral indefinida

F es una primitiva de f si F′(x) = f(x). La integral indefinida es el conjunto de todas las primitivas:

∫ f(x) dx = F(x) + C  ⇔  F′(x) = f(x)
  • El símbolo ∫ es una "S" alargada (de "suma"). El dx indica cuál es la variable: no es decoración, y en sustitución se usa.
  • La constante C está porque la derivada de una constante es 0: x², x² + 5 y x² − 3 tienen la misma derivada, 2x.
  • Siempre podés verificar derivando el resultado: si te da la función de adentro, está bien.

Propiedades (linealidad)

∫ [f(x) ± g(x)] dx = ∫ f dx ± ∫ g dx   ·   ∫ k·f(x) dx = k·∫ f(x) dx
Lo que NO se puede

∫ f·g dx ≠ (∫ f dx)·(∫ g dx). No hay "regla del producto" directa: para eso existen la sustitución y las partes. Tampoco hay regla del cociente.

En criollo · la regla de la potencia

Para integrar xⁿ: "le sumo 1 al exponente y divido por el exponente nuevo". Es exactamente lo contrario de derivar ("bajo el exponente y le resto 1"). La única excepción es x⁻¹ = 1/x, porque daría dividir por 0: esa da ln|x|.

Errores típicos

∫ sen x dx = −cos x (con menos), porque (cos x)′ = −sen x. Es el error de signo más común.

∫ 1/x dx = ln|x|, con valor absoluto: ln solo existe para positivos.

∫ 1/x² dx ≠ ln(x²). Es una potencia: x⁻² ⇒ x⁻¹/(−1) = −1/x.

04

Método de sustitución (cambio de variable)

Es la regla de la cadena al revés. Sirve cuando dentro de la integral aparecen una función y (casi) su derivada.

Receta

1. Elegí u = "lo de adentro" (lo que está dentro de una potencia, raíz, exponente, seno, ln…).

2. Calculá du = u′(x)·dx.

3. Reemplazá todo para que quede solo u (sin ninguna x). Si sobra una x, la sustitución elegida no sirve.

4. Integrá en u y volvé a x.

Ejemplo · ∫ 2x·(x² + 1)⁵ dx

u = x² + 1 ⇒ du = 2x dx

∫ u⁵ du = u⁶/6 + C = (x² + 1)⁶/6 + C

En criollo

Es ponerle un apodo a la parte complicada. Si la derivada de esa parte ya está multiplicando afuera (o está salvo un número), la integral se vuelve una de tabla. Si falta un número, lo arreglás: "si necesito un 3 y no está, multiplico por 3 adentro y por 1/3 afuera".

1∫ cos(3x) dx
u = 3x, du = 3 dx ⇒ dx = du/3 ⇒ ∫ cos u · du/3 = sen(3x)/3 + C
2∫ x·e^(x²) dx
u = x², du = 2x dx ⇒ x dx = du/2 ⇒ ½ ∫ eᵘ du = e^(x²)/2 + C
3∫ x/(x² + 4) dx
u = x² + 4, du = 2x dx ⇒ ½ ∫ du/u = ½ ln(x² + 4) + C

Patrón muy útil: ∫ u′/u = ln|u|. Si arriba está la derivada de abajo (salvo un número), da un logaritmo.

4∫ (ln x)/x dx  y  ∫ tg x dx Nivel parcial
u = ln x, du = dx/x ⇒ ∫ u du = (ln x)²/2 + C
tg x = sen x/cos x; u = cos x, du = −sen x dx ⇒ −∫ du/u = −ln|cos x| + C
5∫ x·√(x − 1) dx  (sustitución "de despeje") Nivel libro
u = x − 1 ⇒ x = u + 1, dx = du
∫ (u + 1)·u^(1/2) du = ∫ (u^(3/2) + u^(1/2)) du = (2/5)u^(5/2) + (2/3)u^(3/2)
= (2/5)(x − 1)^(5/2) + (2/3)(x − 1)^(3/2) + C

Cuando sobra una x, despejala de la sustitución (x = u + 1) y reemplazala.

05

Integración por partes

Sale de la regla del producto. Sirve para productos de funciones de distinto tipo (un polinomio por una exponencial, x por un seno, ln x solo…).

∫ u dv = u·v − ∫ v du
¿Quién es u? · regla LIATE

Elegí como u la que aparezca primero en esta lista (la otra, con el dx, es dv):

L ogarítmicas → I nversas trig. → A lgebraicas (polinomios) → T rigonométricas → E xponenciales

La idea: u tiene que simplificarse al derivarla, y dv tiene que ser fácil de integrar.

En criollo

Partes es cambiar una integral difícil por otra más fácil. Derivás la parte que se "achica" al derivar (el polinomio va perdiendo grado, el ln se vuelve 1/x) e integrás la que no se complica (eˣ sigue siendo eˣ). Un clásico para memorizarla: "un día vi una vaca vestida de uniforme" (∫u dv = uv − ∫v du).

1∫ x·eˣ dx
u = x ⇒ du = dx · dv = eˣ dx ⇒ v = eˣ
= x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x − 1) + C

Verificación: [eˣ(x − 1)]′ = eˣ(x − 1) + eˣ = x·eˣ ✓.

2∫ x·cos x dx
u = x, dv = cos x dx ⇒ v = sen x
= x·sen x − ∫ sen x dx = x·sen x + cos x + C
3∫ ln x dx  (el truco del "dv = dx")
u = ln x ⇒ du = dx/x · dv = dx ⇒ v = x
= x·ln x − ∫ x·(1/x) dx = x·ln x − x + C

Cuando hay una sola función que no sabés integrar (ln x, arctg x), tomá dv = dx.

4∫ x²·eˣ dx  (partes dos veces) Nivel parcial
u = x², dv = eˣ dx ⇒ = x²eˣ − ∫ 2x·eˣ dx = x²eˣ − 2·[eˣ(x − 1)]
= eˣ(x² − 2x + 2) + C

Un polinomio de grado n necesita n veces partes. Cada vez baja un grado.

5∫ eˣ·sen x dx  (integral "cíclica") Nivel libro
Llamo I a la integral. Partes con u = sen x, dv = eˣ dx: I = eˣ sen x − ∫ eˣ cos x dx
Otra vez partes (u = cos x): ∫ eˣ cos x dx = eˣ cos x + ∫ eˣ sen x dx = eˣ cos x + I
I = eˣ sen x − eˣ cos x − I ⇒ 2I = eˣ(sen x − cos x) ⇒ I = eˣ(sen x − cos x)/2 + C

Después de dos partes vuelve a aparecer la integral original: se despeja como en una ecuación.

06

Fracciones simples (funciones racionales)

Para integrar P(x)/Q(x) (cociente de polinomios) cuando no sirve la sustitución:

Receta

0. Si el grado de P es mayor o igual que el de Q, primero dividí los polinomios.

1. Factorizá el denominador Q(x).

2. Escribí la descomposición: cada factor (x − a) aporta A/(x − a); un factor repetido (x − a)² aporta A/(x − a) + B/(x − a)².

3. Hallá A, B, … (dando valores a x convenientes, como las raíces).

4. Integrá: ∫ A/(x − a) dx = A·ln|x − a| y ∫ B/(x − a)² dx = −B/(x − a).

1∫ (3x + 1)/[(x − 1)(x + 2)] dx
(3x + 1)/[(x − 1)(x + 2)] = A/(x − 1) + B/(x + 2) ⇒ 3x + 1 = A(x + 2) + B(x − 1)
x = 1: 4 = 3A ⇒ A = 4/3 · x = −2: −5 = −3B ⇒ B = 5/3
∫ = (4/3) ln|x − 1| + (5/3) ln|x + 2| + C

El truco de reemplazar x por las raíces anula todos los términos menos uno.

2∫ 1/(x² − 1) dx
1/[(x − 1)(x + 1)] = ½/(x − 1) − ½/(x + 1) ⇒ ∫ = ½ ln|x − 1| − ½ ln|x + 1| + C = ½ ln|(x − 1)/(x + 1)| + C
3∫ (x + 3)/(x − 1)² dx  (raíz doble) Nivel parcial
(x + 3)/(x − 1)² = A/(x − 1) + B/(x − 1)² ⇒ x + 3 = A(x − 1) + B ⇒ A = 1, B = 4
∫ = ln|x − 1| − 4/(x − 1) + C
4∫ (x² + 1)/(x − 1) dx  (grado de arriba ≥ grado de abajo)
Divido: x² + 1 = (x − 1)(x + 1) + 2 ⇒ (x² + 1)/(x − 1) = x + 1 + 2/(x − 1)
∫ = x²/2 + x + 2 ln|x − 1| + C
En criollo

Es "desarmar" una fracción complicada en varias fracciones simples que cada una da un logaritmo. Como cuando sumás 1/2 + 1/3 = 5/6, pero al revés: te dan el 5/6 y tenés que encontrar el 1/2 y el 1/3.

07

Integrales trigonométricas básicas

  • sen²x y cos²x: se usan las fórmulas del ángulo doble: sen²x = (1 − cos 2x)/2 y cos²x = (1 + cos 2x)/2. Así, ∫ sen²x dx = x/2 − sen(2x)/4 + C.
  • senⁿx·cos x (o al revés): sustitución u = sen x. Ej.: ∫ sen³x·cos x dx = sen⁴x/4 + C.
  • Potencia impar de seno: separás un sen x y usás sen²x = 1 − cos²x. Ej.: ∫ sen³x dx = ∫ (1 − cos²x)·sen x dx = −cos x + cos³x/3 + C.
  • Sustitución trigonométrica (para √(a² − x²)): x = a·sen t. Ej.: ∫ dx/√(4 − x²) = arcsen(x/2) + C.

09

Integral definida: sumas de Riemann

¿Cómo se mide el área bajo una curva? Se aproxima con rectángulos: se divide [a, b] en n partes de ancho Δx = (b − a)/n, se arma un rectángulo en cada una (con la altura de la función en un punto) y se suman las áreas. Eso es una suma de Riemann.

La integral definida es el límite de esas sumas cuando los rectángulos se hacen infinitamente finos:

∫ₐᵇ f(x) dx = limn→∞ Σ f(xᵢ)·Δx
Cuenta a mano · n = 4, extremo derecho

Δx = (2 − 0)/4 = 0,5 · puntos: 0,5 ; 1 ; 1,5 ; 2

S = 0,5·(0,25 + 1 + 2,25 + 4) = 0,5·7,5 = 3,75

Con el extremo izquierdo (0 ; 0,5 ; 1 ; 1,5): S = 0,5·(0 + 0,25 + 1 + 2,25) = 1,75

El valor exacto, 8/3 ≈ 2,667, queda entre las dos aproximaciones.

En criollo

Es como calcular la superficie de un terreno con forma rara cubriéndolo con baldosas rectangulares. Con baldosas grandes, la cuenta es aproximada; con baldosas cada vez más chicas, cada vez más exacta. La integral es "baldosas infinitamente finas".

Importante: área con signo

Si la función está por debajo del eje x, los rectángulos tienen altura negativa: la integral definida resta esa parte. Por eso integral definida y área no siempre son lo mismo (ver sección 12).

10

Teorema fundamental del cálculo y regla de Barrow

Hacer sumas de Riemann con n → ∞ sería eterno. El Teorema Fundamental del Cálculo conecta todo:

Parte 1: si F(x) = ∫ₐˣ f(t) dt, entonces F′(x) = f(x)

Parte 2 (Barrow): ∫ₐᵇ f(x) dx = F(b) − F(a), con F primitiva de f

En criollo: para calcular una integral definida buscás una primitiva, la evaluás arriba, la evaluás abajo y restás. La constante C no hace falta (se cancela). Se anota [F(x)]ₐᵇ.

Ejemplos

∫₀² x² dx = [x³/3]₀² = 8/3 − 0 = 8/3

∫₀^π sen x dx = [−cos x]₀^π = −cos π − (−cos 0) = 1 + 1 = 2

∫₁^e (1/x) dx = [ln x]₁^e = 1 − 0 = 1

Sustitución en definidas

Si hacés un cambio de variable, cambiá también los límites: ∫₀¹ 2x(x² + 1)³ dx, con u = x² + 1: x = 0 ⇒ u = 1 y x = 1 ⇒ u = 2. Queda ∫₁² u³ du = [u⁴/4]₁² = 4 − 1/4 = 15/4. Así no tenés que volver a x.

EjDerivá F(x) = ∫₁^(x²) ln t dt (sin calcular la integral). Nivel parcial
TFC + cadena: F′(x) = ln(x²)·(x²)′ = 2x·ln(x²) = 4x·ln x (para x > 0)

Si el límite superior es g(x) en vez de x, se multiplica por g′(x).

En criollo

Para saber cuánta agua entró a un tanque entre las 2 y las 5, no hace falta sumar segundo a segundo: mirás cuánto marcaba el medidor a las 5 y le restás lo que marcaba a las 2. La primitiva es ese "medidor acumulado".

Cálculo de áreas

Área entre una curva y el eje x

Si f cambia de signo, hay que partir la integral en los ceros y sumar los valores absolutos. Si integrás de corrido, las partes negativas restan.

Receta para áreas con el eje x

1. Buscá los ceros de f dentro del intervalo. 2. Integrá en cada tramo por separado. 3. Sumá los valores absolutos.

Área entre dos curvas

Área = ∫ₐᵇ [ f(x) − g(x) ] dx   (f = la de arriba, g = la de abajo)
Receta

1. Igualá f(x) = g(x) para hallar los cortes (son los límites de integración). 2. Decidí cuál está arriba (probá un punto del medio). 3. Integrá "arriba menos abajo".

1Área entre y = x e y = x² Accesible
Cortes: x = x² ⇒ x = 0 y x = 1. En x = 0,5: x = 0,5 > x² = 0,25 ⇒ arriba está y = x
A = ∫₀¹ (x − x²) dx = [x²/2 − x³/3]₀¹ = 1/2 − 1/3 = 1/6
2Área entre f(x) = 4 − x² y g(x) = x + 2 Nivel parcial
4 − x² = x + 2 ⇒ x² + x − 2 = 0 ⇒ x = −2, x = 1 · En x = 0: f = 4 > g = 2
A = ∫₋₂¹ (2 − x − x²) dx = [2x − x²/2 − x³/3]₋₂¹ = (7/6) − (−10/3) = 9/2
En criollo

El área entre dos curvas es "el techo menos el piso", sumado de un corte al otro. Si en algún tramo se cruzan y el techo pasa a ser piso, hay que partir ahí.

Integrales impropias

Son integrales con un límite infinito, o con una función que se va a infinito dentro del intervalo. Se calculan con un límite:

∫ₐ^∞ f(x) dx = limb→∞ ∫ₐᵇ f(x) dx

Si el límite da un número, la integral converge; si da ∞ o no existe, diverge.

IntegralCálculoResultado
∫₁^∞ 1/x² dxlim [−1/x]₁ᵇ = lim (1 − 1/b)1 (converge)
∫₁^∞ 1/x dxlim [ln x]₁ᵇ = lim ln b∞ (diverge)
∫₀^∞ e^(−x) dxlim [−e^(−x)]₀ᵇ = lim (1 − e^(−b))1 (converge)
En criollo

Una región infinitamente larga puede tener área finita, si la curva baja lo bastante rápido (como 1/x²). Con 1/x no alcanza: baja, pero tan despacio que el área sigue creciendo para siempre.
